## 题目概要

根据历届夏季奥运会的奖牌数据建立模型，主要任务包括：
1. 预测 2028 年洛杉矶奥运会奖牌榜，判断哪些国家会进步或退步
2. 预测尚未获得过奖牌的国家中，谁最有可能拿到首枚奖牌
3. 分析比赛项目与各国奖牌数之间的关系，包括东道主设项的影响
4. 评估"名帅效应"对一国获奖概率的影响
5. 总结模型对各国奥委会的启示并提出建议

## 我们的模型

| 任务 | 方法 | 主要结论 |
|---|---|---|
| 任务 1：预测 2028 奖牌榜 | 将各国按历史表现分为五类；表现稳定的国家用线性回归 + ARIMA 预测并做 ADF 平稳性检验；表现不稳定的国家（中国台北、南非、乌兹别克斯坦）按 2000 年后重点运动员的获奖概率估算 | 与 2024 年相比，古巴最可能进步，法国最可能退步 |
| 任务 2：首枚奖牌 | 筛选未获奖国家，分析其参赛项目与竞争格局，用逻辑回归计算获奖概率 | 各国概率相近，AND 排名第一，其次为 NFL、ROT 等 |
| 任务 3：项目与奖牌 | Apriori 关联规则挖掘（分别以国家、项目为前件，按置信度排序） | 美国优势在游泳和田径；东道主通常会增设自身优势项目，因此 2028 年与美国优势项目相同的澳大利亚、英国、中国奖牌数可能增加 |
| 任务 4：名帅效应 | 逻辑分析 + 案例（印度足球、卡塔尔足球、巴西网球） | 提出投资"名帅"的三个前提：曾有获奖基础、因教练离任而成绩下滑、具备相应经济实力 |
| 任务 5：建议 | 基于平稳性与 ARIMA 参数的解读 | 成绩稳定的国家巩固优势项目；成绩波动大的国家应调整政策与人才培养，并据此合理分配资源 |
